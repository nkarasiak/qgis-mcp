about=Companion QGIS plugin for the qgis-mcp-north MCP server. Exposes a TCP
    socket that the server connects to so that LLMs can drive figure
    rendering, choropleths, trajectory plots, and OD-flow maps without
    leaving Claude.

    This plugin is intentionally narrow — focused on transportation research
    workflows (PFLOW, GUFM, weekly-deck figure pipelines). For the general
    51-tool QGIS-MCP surface, install nkarasiak/qgis-mcp side-by-side
    (different plugin folder, different socket port).

    Pair this plugin with the qgis-mcp-north MCP server. See
    https://github.com/wattwong103/qgis-mcp-north for setup instructions.

    Default socket port: 9877 (vs upstream nkarasiak/qgis-mcp on 9876).
