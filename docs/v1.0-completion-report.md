### Compound mode (PR 2)

`QGIS_MCP_NORTH_TOOL_MODE=compound` collapses the 13-tool surface to **5 grouped tools** for token-constrained LLMs:

| Compound tool | Discriminator | Replaces |
|---|---|---|
| `qgis_inspect` | `kind: "layer" \| "project"`, `register: bool` | `qgis_layer_inspect`, `qgis_load_layer`, `qgis_project_load` |
| `qgis_style` | `type: "categorized" \| "graduated"` | `qgis_style_categorized`, `qgis_style_graduated` |
| `qgis_render` | `mode: "map" \| "choropleth" \| "trajectory" \| "od_flows"` | the 4 render tools |
| `qgis_export` | `kind: "layout" \| "batch" \| "pptx"` | `qgis_export_layout`, `qgis_batch_render`, `qgis_figures_to_pptx` |
| `qgis_eval` | (unchanged) | escape hatch |

Implementation: `_maybe_tool` / `_maybe_compound_tool` decorators wrap `mcp.tool` and conditionally register based on the env var. Standalone tool functions stay as Python callables in both modes (direct imports from tests always work). Compound module at `src/qgis_mcp_north/compound.py`; 7 tests in `tests/test_compound_mode.py`.

### E2E W17 demo (PR 4)

`scripts/demo_w17.py` — standalone, runnable as `uv run scripts/demo_w17.py`. Six-step pipeline using only synthetic fixtures:

1. `qgis_layer_inspect(tiny_zones.geojson)` — sanity check (asserts 4 zones).
2. Build synthetic `zone_id,total_trips` CSV (deterministic values: 1200, 850, 430, 2100).
3. `qgis_render_choropleth(zones, value_csv, total_trips, ...)`.
4. `qgis_render_trajectory(tiny_trajectory.csv, render_mode="heatmap")`.
5. `qgis_render_od_flows(tiny_od.csv, tiny_zones.geojson, ...)`.
6. `qgis_figures_to_pptx([01, 02, 03], "w17.pptx", layout="title_and_image")`.

Three execution modes via `tests/integration/test_w17_demo.py`:
- **fake**: dispatch chain through `FakeExecutor`. Always runs.
- **plugin**: `@requires_plugin`. Skipped unless port 9877 is open.
- **headless**: `@requires_headless`. Skipped unless `QGIS_MCP_NORTH_QGIS_LAUNCHER` is set.

Output PNG → `assets/screenshots/w17_demo.png` (committed via the demo's own script for reproducibility).

### Plugin / headless E2E (manual, on your machine)

These steps are gated behind QGIS being available. Per the user's "Windows-only v1.0" decision, only the Windows + OSGeo4W LTR path is claimed.

```powershell
# Plugin mode (QGIS Desktop open, plugin enabled on :9877)
uv run --no-sync scripts/demo_w17.py

# Headless mode
$env:QGIS_MCP_NORTH_TRANSPORT='headless'
$env:QGIS_MCP_NORTH_QGIS_LAUNCHER='M:\QGIS LTR\bin\python-qgis-ltr.bat'
uv run --no-sync scripts/demo_w17.py

# Compound mode E2E
$env:QGIS_MCP_NORTH_TOOL_MODE='compound'
uv run --no-sync scripts/demo_w17.py
```

Each should produce `tmp/demo_w17_<mode>/w17.pptx` with 3 slides. The choropleth slide is also copied to `assets/screenshots/w17_demo.png` for the README.

## Risks accepted

1. **Compound mode + Pydantic discriminated unions.** Implemented without formal discriminated unions (just Literal + match dispatch). FastMCP handles the optional-union arguments cleanly. Token savings ~60% on tool-schema bytes (uncounted; would need an MCP-introspection script).
2. **`qgis_eval` security.** Runs arbitrary Python; annotated `destructiveHint=True`. Acceptable for single-user research; flag for v2+ if multi-tenant deployments emerge.
3. **Benchmark numbers are single-machine.** v0.5 baseline doc is a template; user fills in on their hardware.
4. **README screenshot drift.** `assets/screenshots/w17_demo.png` regenerates from the demo; will drift if default colors change. Acceptable per the plan.
