## New error classes

- `EmptyAfterFilterError` — extent clip or sampling left 0 features (trajectory).
- `ProjectLoadError` — `.qgz` read failure with reason.
- `LayoutNotFoundError` — print-composer name missing; lists available layouts.

All three end with "Next: …" recovery hints per DESIGN.md §5.

## Lessons

- The v0.4 stub-iface architecture worked exactly as promised: 5 new plugin handlers ship with both transports for free.
- Test fixture strategy (synthetic-only) keeps PR1+PR2 CI-runnable; real PFLOW data stays on the user's machine.
- The `JOIN_NO_MATCH`/`LAYOUT_NOT_FOUND`/`FIELD_NOT_FOUND` marker-in-message pattern is a clean way to map generic `ExecutorError` to typed MCP errors without adding plugin-side complexity.
